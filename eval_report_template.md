# Evaluation report template

## Scope
Define the evaluation boundary, task distribution, and target behaviors evaluated in this run.

## Rubric version
Record the active rubric version identifier, revision date, and key changes from previous revisions.

## Sampling method
Describe the dataset selection, stratification strategy, sample size, and split criteria.

## Per-item tags
Document the categorical labels applied to each test item, including difficulty tier, domain, and prompt format.

## Failure-mode counts
Summary table of observed failure categories and occurrence frequencies across evaluated items.

## Known ambiguities
List ambiguous test cases, unclear reference outputs, or edge cases identified during manual review.

## Reproducibility note
Specify the environment settings, model configuration parameters, temperature, random seed, and execution steps to reproduce the evaluation run.
