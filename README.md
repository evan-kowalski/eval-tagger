# eval-tagger

Utilities for tagging and filtering evaluation outputs.

## Usage

Inspect eval_report_template.json for the standard report schema. Use this schema to record benchmark runs, metrics, and tags.

## Evaluation report template usage

The eval_report_template.md file provides a standard structure for documenting evaluation runs. Copy the template for each evaluation cycle and fill in each section: define the scope, specify the rubric version, outline the sampling method, record item tags, tally failure modes, note any ambiguities, and record environment details for reproducibility.
